OwnerBot is a cloud data security framework that integrates Homomorphic Encryption and Blockchain to ensure confidentiality, integrity, and secure sharing of sensitive data.

Key Features

Encrypts data using homomorphic encryption (processed without decryption).

Blockchain ledger for tamper-proof integrity verification.

OwnerBot acts as a trusted intermediary for re-encryption and secure file sharing.

Audit logs enable transparency, traceability, and accountability.

Role-based access: Data Owner & Data User.


How It Works

1. Data Owner encrypts and uploads files to the cloud.


2. Blockchain stores file hashes and access logs.


3. Data User requests access; OwnerBot re-encrypts file for the user.


4. Data User decrypts with private key.


5. Data Owner audits logs to verify integrity.



Tech Stack

Backend: Python (Flask)

Database: MySQL

Blockchain: Ethereum/Web3

Crypto: PyCryptodome, Homomorphic Encryption


Results

Fast encryption & accurate decryption

Blockchain prevents tampering

Unauthorized access blocked

Scalable and user-friendly
